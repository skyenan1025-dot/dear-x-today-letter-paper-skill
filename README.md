# Dear X, Today — 信纸生成 Skill

[中文](README.md) · [한국어](README.ko.md) · [English](README.en.md)

**当前版本：v1.0.0** · [版本记录](CHANGELOG.md)

> I lived this day, and made it into a letter for you.  
> 我认真生活了这一天，然后把它做成一封信寄给你。

`create-dear-x-letter-paper` 是一个面向 ChatGPT / Codex 的图片生成工作流 Skill。它可以根据一张或多张参考照片，生成四周带有照片衍生装饰、中间保留大面积书写区域的专属信纸。

它适合制作追星信纸、粉丝信背景、纪念日信纸、照片主题手账纸，以及适合打印或数字书写的个性化 stationery。

## 它能做什么

- 保留主图人物或主体的可识别特征。
- 从主图提取配色、光线、季节与情绪氛围。
- 从其他照片中识别并提取花朵、饮品、票根、服饰纹样、建筑、玩具和生活物件等装饰元素。
- 将不同照片中的元素统一成轻盈的 Instagram 拼贴风格。
- 默认在页面中间保留约 65%–75% 的干净书写区域。
- 支持调整留白比例、人物位置、装饰密度、方向、比例、背景色与整体风格。
- 生成平整、正面的完整信纸，而不是桌面摆拍或产品样机。

## 工作原理

这个仓库不包含图片生成模型，也不提供独立的图片生成 API。

Skill 的作用是为具备图片生成或图片编辑能力的 AI 提供一套稳定、可复用的设计流程：

1. 将用户指定的照片，或第一张照片，作为主图。
2. 使用主图确定人物身份、主要配色、光线和整体氛围。
3. 将其余照片作为装饰元素来源，而不是直接拼成多个大图块。
4. 从每张辅助照片中选择 1–3 个有辨识度的元素。
5. 统一所有元素的色相、饱和度、颗粒、描边和阴影语言。
6. 将人物与装饰安排在页面边缘，保护中间的书写区域。
7. 检查人物、留白、文字、水印、重复元素和打印可用性后输出成品。

因此，最终能否生成图片，取决于使用环境是否提供可用的图片生成或编辑工具。

create-dear-x-letter-paper/

    └── design-system.md

- `SKILL.md`：核心触发条件、执行流程、用户控制项和质量检查规则。
- `references/design-system.md`：构图分区、多图元素提取、风格与视觉层级规范。

- `assets/icon.svg`：Skill 图标。

## 安装

将完整的 `create-dear-x-letter-paper` 文件夹添加到支持自定义 Skill 的 ChatGPT / Codex 环境中。安装后，可以直接在消息中点名调用它。

不同版本和使用环境的安装入口可能不同；请以你当前产品中的 Skills 页面或官方说明为准。

## 基础调用

上传一张照片，然后输入：

```text
使用 @create-dear-x-letter-paper，把这张照片制作成 Dear X, Today 专属信纸。
保留人物真实特征，中间留出大面积书写区域，周围使用从照片中提取的元素进行装饰。
```

## 多照片调用示例

```text
请用第一张照片作为主图，保留人物的脸、发型和服装特征。
从后面三张生活照片中提取花束、咖啡杯、车票和天空颜色作为装饰，
生成一张竖版 A4 信纸。整体采用轻盈的 Instagram 拼贴风格，
中间保留约 75% 的干净书写区域，人物放在右下角，不添加文字、水印或桌面样机。
```

## 可以怎样调整

你可以直接使用自然语言提出修改：

- “空白区域再大一点，调整到 82% 左右。”
- “人物移到左下角，其他内容保持不变。”
- “装饰元素再丰富一点，但不要进入中间书写区。”
- “改成横版 4:3，适合平板书写。”
- “背景换成从照片中提取的浅蓝灰色。”
- “减少复古贴纸，整体更像干净的杂志编辑风。”

未被提及的设置应在修改时保持不变。

## 默认设计规范

- 方向：竖版。
- 中央留白：约 65%–75%。
- 主体位置：页面一侧或下方角落。
- 装饰分布：顶部、两侧和下方角落的不对称小组团。
- 风格：轻盈、统一、不过度堆叠的 Instagram 拼贴。
- 配色：从主图提取 3–6 种颜色。
- 输出：无手持、桌面、装订、折痕、纸张投影和预设正文。

## 使用限制

- 必须提供需要参考的照片；Skill 不应凭记忆模仿缺失的人物。
- Skill 会尽量保持主体可识别，但图片生成工具仍可能产生面部、手部或细节偏差。
- 图片内的准确文字通常不是生成模型的强项，建议生成无文字信纸后再使用设计软件排版。
- 打印前请检查尺寸、分辨率、色彩模式和出血设置。
- 请确保你有权使用上传的照片，并遵守相关肖像权、版权和平台规则。

## 项目愿景

“X”可以是任何想念的人，也可以是任何值得被记录的对象。

Dear X, Today 希望把一天里真实生活过的片段，变成一张可以写下心意、保存回忆并寄给对方的信纸。
