# Changelog

All notable changes to **Dear X, Today — Letter Paper Generation Skill** will be recorded in this file.

The version format follows [Semantic Versioning](https://semver.org/):

- Patch `v1.0.1`: small fixes or prompt refinements.
- Minor `v1.1.0`: new controls, styles, or compatible workflows.
- Major `v2.0.0`: changes that significantly alter existing behavior or usage.

## [v1.0.0] — 2026-08-20

### Added

- Initial public release of `create-dear-x-letter-paper`.
- Single-photo and multi-photo stationery generation workflows.
- Main-photo anchoring for identity, palette, lighting, and mood.
- Supporting-photo element extraction for unified border decoration.
- Adjustable blank-area ratio, orientation, subject placement, subject scale, decoration density, background, and style.
- Default light Instagram-inspired collage design system.
- Print-friendly, front-facing stationery composition guardrails.
- Chinese, Korean, and English README documentation.
- ChatGPT / Codex interface metadata and project icon.

### Notes

- This Skill does not bundle an image model or standalone image-generation API.
- A compatible image-generation or image-editing tool is required in the host environment.
- Photos, portraits, and example assets remain subject to their own copyright and permission requirements.
