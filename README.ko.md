# Dear X, Today — 편지지 생성 Skill

[中文](README.md) · [한국어](README.ko.md) · [English](README.en.md)

**현재 버전: v1.0.0** · [변경 기록](CHANGELOG.md)

> I lived this day, and made it into a letter for you.  
> 나는 오늘을 성실히 살아냈고, 그 하루를 너에게 보낼 편지로 만들었다.

`create-dear-x-letter-paper`는 ChatGPT / Codex에서 사용할 수 있는 이미지 생성 워크플로 Skill입니다. 한 장 또는 여러 장의 참고 사진을 바탕으로, 가장자리에는 사진에서 가져온 장식 요소를 배치하고 중앙에는 넓은 필기 공간을 남긴 맞춤형 편지지를 만듭니다.

팬레터 편지지, 기념일 편지지, 사진 테마 다이어리 용지, 인쇄용 또는 디지털 필기용 맞춤 stationery 제작에 적합합니다.

## 주요 기능

- 메인 사진 속 인물이나 대상의 식별 가능한 특징을 유지합니다.
- 메인 사진에서 색상, 빛, 계절감과 분위기를 추출합니다.
- 추가 사진에서 꽃, 음료, 티켓, 의상 패턴, 건물, 장난감, 일상 소품 등의 장식 요소를 골라냅니다.
- 서로 다른 사진의 요소를 가볍고 통일된 Instagram 콜라주 스타일로 정리합니다.
- 기본적으로 페이지 중앙의 약 65%–75%를 깨끗한 필기 공간으로 남깁니다.
- 여백 비율, 인물 위치, 장식 밀도, 방향, 화면 비율, 배경색과 스타일을 조정할 수 있습니다.
- 책상 위 연출 사진이나 목업이 아닌, 평평한 정면 편지지 한 장으로 출력합니다.

## 작동 방식

이 저장소에는 이미지 생성 모델이 포함되어 있지 않으며, 독립적인 이미지 생성 API도 제공하지 않습니다.

이 Skill은 이미지 생성 또는 편집 기능을 갖춘 AI에게 일관되고 재사용 가능한 디자인 절차를 제공합니다.

1. 사용자가 지정한 사진 또는 첫 번째 사진을 메인 사진으로 정합니다.
2. 메인 사진을 기준으로 인물, 주요 색상, 조명과 전체 분위기를 결정합니다.
3. 나머지 사진은 큰 사진 타일이 아니라 장식 요소의 출처로 사용합니다.
4. 각 보조 사진에서 특징적인 요소 1–3개를 선택합니다.
5. 모든 요소의 색조, 채도, 질감, 외곽선과 그림자 표현을 통일합니다.
6. 인물과 장식을 페이지 가장자리에 배치하고 중앙 필기 공간을 보호합니다.
7. 인물 표현, 여백, 의도하지 않은 글자나 워터마크, 반복 요소와 인쇄 적합성을 확인한 뒤 결과물을 출력합니다.

따라서 실제 이미지 생성 가능 여부는 사용 환경에 이미지 생성 또는 편집 도구가 제공되는지에 따라 달라집니다.

## 파일 구조

```text
create-dear-x-letter-paper/
├── SKILL.md
├── agents/
│   └── openai.yaml
├── assets/
│   └── icon.svg
└── references/
    └── design-system.md
```

- `SKILL.md`: 실행 조건, 전체 워크플로, 사용자 조정 항목과 품질 점검 규칙.
- `references/design-system.md`: 레이아웃 영역, 다중 사진 요소 추출, 스타일과 시각적 위계 규칙.
- `agents/openai.yaml`: 표시 이름, 설명, 기본 프롬프트와 아이콘 설정.
- `assets/icon.svg`: Skill 아이콘.

## 설치

전체 `create-dear-x-letter-paper` 폴더를 사용자 정의 Skill을 지원하는 ChatGPT / Codex 환경에 추가하세요. 설치 후 메시지에서 Skill 이름을 직접 지정해 사용할 수 있습니다.

제품 버전과 사용 환경에 따라 설치 경로가 다를 수 있으므로, 현재 사용 중인 제품의 Skills 페이지 또는 공식 안내를 확인하세요.

## 기본 사용 예시

사진 한 장을 업로드한 뒤 다음과 같이 입력합니다.

```text
@create-dear-x-letter-paper를 사용해 이 사진을 Dear X, Today 전용 편지지로 만들어 줘.
인물의 실제 특징을 유지하고, 중앙에는 넓은 필기 공간을 남겨 줘.
가장자리는 사진에서 추출한 요소로 장식해 줘.
```

## 여러 장의 사진을 사용하는 예시

```text
첫 번째 사진을 메인 사진으로 사용하고 인물의 얼굴, 헤어스타일과 의상 특징을 유지해 줘.
나머지 세 장의 일상 사진에서는 꽃다발, 커피잔, 승차권과 하늘색을 장식 요소로 추출해 줘.
세로형 A4 편지지로 만들고, 전체적으로 가벼운 Instagram 콜라주 스타일을 적용해 줘.
중앙의 약 75%는 깨끗한 필기 공간으로 남기고 인물은 오른쪽 아래에 배치해 줘.
글자, 워터마크 또는 책상 위 목업은 추가하지 마.
```

## 조정 가능한 항목

자연어로 바로 수정 요청을 할 수 있습니다.

- “빈 공간을 더 넓혀서 약 82%로 조정해 줘.”
- “인물을 왼쪽 아래로 옮기고 나머지는 그대로 유지해 줘.”
- “장식은 조금 더 풍부하게 하되 중앙 필기 공간에는 들어오지 않게 해 줘.”
- “태블릿 필기에 적합한 가로형 4:3으로 바꿔 줘.”
- “배경을 사진에서 가져온 연한 블루 그레이로 변경해 줘.”
- “레트로 스티커를 줄이고 깔끔한 에디토리얼 스타일로 바꿔 줘.”

수정 요청에서 언급하지 않은 설정은 그대로 유지해야 합니다.

## 기본 디자인 규칙

- 방향: 세로형.
- 중앙 여백: 약 65%–75%.
- 인물 위치: 페이지 한쪽 또는 아래쪽 모서리.
- 장식 배치: 위쪽, 양옆과 아래 모서리에 비대칭 소규모 클러스터.
- 스타일: 가볍고 통일감 있으며 과도하게 쌓이지 않는 Instagram 콜라주.
- 색상: 메인 사진에서 추출한 3–6가지 색상.
- 출력: 손, 책상, 제본, 접힌 자국, 종이 그림자와 미리 작성된 본문을 포함하지 않음.

## 사용 시 유의사항

- 참고할 사진을 반드시 제공해야 하며, 누락된 인물을 기억에 의존해 재현하지 않습니다.
- Skill은 인물의 식별 가능성을 유지하도록 설계되었지만, 이미지 생성 도구에서 얼굴, 손 또는 세부 묘사 오류가 발생할 수 있습니다.
- 이미지 생성 모델은 정확한 글자 표현에 한계가 있으므로, 글자가 없는 편지지를 만든 뒤 디자인 도구에서 문구를 추가하는 방식을 권장합니다.
- 인쇄 전 크기, 해상도, 색상 모드와 도련 설정을 확인하세요.
- 업로드하는 사진을 사용할 권한이 있는지 확인하고 초상권, 저작권 및 플랫폼 정책을 준수하세요.

## 프로젝트 비전

“X”는 그리운 누구든, 기록하고 싶은 어떤 대상이든 될 수 있습니다.

Dear X, Today는 하루 동안 실제로 살아낸 순간들을 마음을 적고, 추억으로 남기고, 누군가에게 보낼 수 있는 한 장의 편지지로 바꾸고자 합니다.
